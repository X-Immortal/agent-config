# 技术栈模块：Element Plus

本文件为可自由组合的**独立技术栈模块**，适用于采用 Element Plus 作为 UI 组件库的 Vue 3 前端项目。

## 1. 按项目约定接入与复用标准组件

- 沿用项目的按需或完整引入方式，优先复用 `el-form`、`el-input`、`el-select`、`el-table`、`el-pagination` 等适合需求的组件；原生控件或已有组件更适合时可保留，避免仅为统一库来源而替换。

## 2. 主题定制与全局反馈

1. **CSS 变量定制品牌视觉**
   - 通过覆盖 Element Plus 的全局 CSS 变量（如 `--el-color-primary` 及其色阶、边框圆角、背景色变量）融合项目的品牌主题色与页面冷暖色调，保持整体视觉协调。
2. **按反馈语义选择组件**
   - 短暂结果可使用 `ElMessage`；字段校验使用表单内反馈，需持续呈现的信息可使用 `ElAlert` 或通知区域。位置与持续时间按项目约定和可访问性要求设置。
