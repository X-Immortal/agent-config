# 技术栈模块：Docker Compose & Nginx

本文件为可自由组合的**独立技术栈模块**，适用于采用 Docker、Docker Compose 与 Nginx 进行容器化开发与部署的项目。

## 1. 极简 Dockerfile 编写

- 前后端 `Dockerfile` 仅保留构建与启动所需的最小必要指令集，保持镜像层次清晰直接，在中小型或演示项目中省去非必要的非 `root` 用户转换、冗余系统工具包（如 `curl`）安装及复杂包装脚本。

## 2. 开发与生产 Compose 编排及 Nginx 边界

1. **前端静态 Nginx 与入口反向代理分离**
   - 前端容器内的 Nginx 仅负责托管前端静态构建产物与前端路由回退（`try_files`）。
   - API 反向代理（`/api` 转发）与 HTTPS 卸载由生产环境的入口网关 Nginx（或宿主机已有的 Nginx 服务）统一处理，与前端静态容器配置保持解耦。
2. **按目标服务器现状编排生产容器**
   - 若目标服务器宿主机已运行统一的 Nginx 服务，生产环境 `docker-compose.prod.yml` 仅编排前端静态容器、后端服务容器与数据库容器，无需额外部署重复的入口 Nginx 容器。
3. **持久化数据卷与动态资源挂载**
   - 数据库数据目录通过命名 Docker Volume 持久化；数据库初始化脚本与配置文件通过 `/docker-entrypoint-initdb.d` 和配置挂载点自动注入。
   - 运行时动态上传的文件目录（如用户上传的图片/附件）通过 Volume 仅挂载给后端服务容器。
